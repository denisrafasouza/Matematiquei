# 📚  Aplicativo Matematiquei
link = https://denisrafasouza.github.io/Matematiquei/


Este projeto foi criado para ajudar estudantes a aprender Matemática de forma simples, visual e interativa.

## 🎯 Objetivo
Facilitar o estudo das funções matemáticas através de explicações e exemplos práticos.

## 📖 Conteúdos
- Introdução às funções
- Limites
- Derivadas
- Integrais
- Gráficos interativos

## 💻 Como utilizar
1. Acede ao site.
2. Escolhe o conteúdo que desejas estudar.
3. Acompanha as explicações e explora os exemplos.

## 🚀 Tecnologias utilizadas
- HTML
- CSS
- JavaScript
- Bibblioteca = math.js (v 12.4.2)
